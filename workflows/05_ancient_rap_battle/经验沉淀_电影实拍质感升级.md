## 1. 核心结论

1. **「AI 数字感」95% 来自光学物理违和与后期管线破坏，而非分辨率不够高。** 把 `f/11` 全景锐利背景直塞给特写、平光暖黄或纯冷光打脸、以及在 `768p` 下叠两次锐化与彩噪再放大，才是画面像「塑料小人贴纸」的真正元凶。
2. **定版默认不加 `Tessera 2.7K`（`--tessera-2k`），单集成本保持 `~12–16 CCU`。** 实测 Stage-1（`Singularity v1.3` 12 步 `1344×768`）仅约 `0.51 CCU/条`，而叠加 Stage-2 `2.7K` 精修后飙升至 `2.46 CCU/条`（贵约 4.8 倍）；经 YouTube/B 站 1080p 流媒体压缩后两者肉眼几乎无差别，100% 核心质感跃升均已由 V3 标准版提供。
3. **口型锁音零退化**：切换 `Singularity v1.3` + 12 步 + 贴唇 45° 前景麦克风后，`A07 / B03 / B08` 音轨锁音相关度达 `0.969–0.998`，无一帧挡嘴。

## 2. 「AI 数字感」六大病灶与根治方案

| # | 原管线病灶（为什么像 AI CG） | 量化异常指标（原片实测） | Realism V3 根治方案 | 定版后指标 |
|---|---|---|---|---|
| 1 | **景深陷阱（`f/11` 全景裁切当特写背景）**：把 `venue.png` 裁出的全清晰 `stage_a/b.png` 连同 `Background: fully_preserved` 喂给近景，H3 强行在歌手耳后画出 10px 刀刻五官的静止微缩假人 | 背景边缘梯度极高、观众帧差低 | `film_optics.py` 在线性光空间（`sRGB^2.4`）做 `r=16` 圆盘光圈 FFT 卷积 + 压暗上方白昼冷窗 + 放大 `2700K` 烛台高光；提示词改为 `Background: reference` + `Cooke Panchro T2.2` 沸腾人潮剪影 | 五官恐怖谷彻底融化，保留欢呼学者剪影与挥手动态 |
| 2 | **光比扁平 / 单一色温偏色**：原版正面大平光（光比 `1.5:1`）像棚拍 CG；V2 纯 `5600K` 冷白光把人脸照成青灰缺血色 | 原版 `SatP90 = 1.00` 过饱溢出；V2 `SatMean = 0.21` 偏冷灰 | **双色温电影布光**：`3200K` 暖钨丝伦勃朗侧主光（`4:1` 光比，雕刻红润血色肌肤）+ `5600K` 冷银顶逆发丝轮廓光 + `2700K` 暖烛台背景散景；配合人像 `warm_skin_boost=0.18` | `SatMean = 0.28–0.30`（自然电影肤色），银白发丝逆光分离度极高 |
| 3 | **双重压暗 + 多重锐化 + `4:2:0` 彩噪放大**：`assemble.py` 先压 `gamma=0.95` 加 `alls=4` 彩噪 → `package.py` 再叠 `cas=0.25` 与二次 `alls=4` → 最后 `unsharp` 放大到 `1080p`，把彩噪放大 2 倍并镶出白边 | 暗部 `P05 = 0.0`，**`18%–33%` 像素死黑归零**，红绿彩斑明显 | `assemble.py --film` 输出无调色纯净母带（关掉非甩镜段的 2px 量化微抖）；`package.py --film --1080p` **先 Lanczos 超采到 1080p**，再单通施加高阈值 `Pro-Mist 1/8`、紧致 Vision3 S 曲线与 **1080p 纯亮度细银盐颗粒**（`c0s=3:c1s=0:c2s=0`） | `P05 = 6.2–7.7`，死黑占比 `<4.5%`，零色度噪点、零锐化白边 |
| 4 | **底模皮肤油光**：默认 `convrot` 8 步蒸馏模型高频纹理偏塑料硅胶反光 | 额头/鼻翼高光僵硬 | `--realism-v2 --steps 12` 启用 `Singularity_ref2va_Pruned_v1.3_int8` + `Realism=0.75` + `Closeup=0.45`（双人 `0.25`、远景 `0`）+ `shift_audio=3.0` + `SigmasTail(3, 0.50)` | 哑光真实毛孔、胡茬与丝绒礼服织物肌理 |
| 5 | **胸口端麦与上半脸面瘫**：麦克风端在胸口像年会朗诵，嘴在动但眉弓/鼻梁不动 | 画面缺少前景纵深与攻击性 | 手持麦改为**下唇下方 1 英寸、45° 斜举压在画面底边**（镀铬网头呈浅景深前景透视，绝不遮上唇与下颌）；提示词显式驱动眉弓压低、鼻梁皱起与颈部青筋 | 对标片同款 Underground 贴麦压迫感，全脸肌肉联动 |
| 6 | **荧光贴纸感字幕与 Emoji 方框**：纯白描黑边 + `#FFE14A` 荧光黄高亮词悬浮在胶片画面上；现代彩色 Emoji（如 `🔬`）在 `NotoSerifSC` 字体下变 `[X]` 方框 | 字幕与 `35mm` 底片脱节 | `--film` 模式自动将字幕改为暖象牙白 `#F4EFE6` + 琥珀金 `#E5A93C` 高亮词 + 柔化阴影；角标与文案严禁放彩色 Emoji，统一用几何符号 `◆` / `·` | 字幕自然融入胶片影调，零缺字方框 |

## 3. 三轮盲测摸出的黄金参数边界（踩坑实录）

这一节记录**不能随便改大或改小**的临界值——每一组都是在真实抽帧和直方图核验里踩出来的：

### 3.1 舞台参考图散景半径（`scripts/film_optics.py` → `make_bokeh_plate`）

| 试验参数 | 实测画面表现 | 结论 |
|---|---|---|
| 不处理（原图 `f/11`） | 特写歌手背后粘着一排 10px 刀刻五官的静止观众，一眼假 | ❌ 禁用 |
| `r=28` + `dark_concert=True`（环境压暗至 `0.12`） | 背景观众与木质看台被彻底抹成一片空荡荡的黑棚，丢掉了地下擂台的热烈临场感 | ❌ 过重（V2 踩坑） |
| `r=10` + `arena_crowd=True` | 远景散景有了，但前排学者的眼鼻轮廓仍隐约可辨，且上方窗户透出白天冷蓝光 | ⚠️ 偏弱 |
| **`r=16` + `arena_crowd=True` + 上方冷窗抑制** | **前排五官完全化开，同时保留欢呼人群头部剪影、高举的手臂与 `2700K` 暖烛台圆盘光斑，夜晚地下擂台氛围拉满** | ✅ **定版甜点** |

### 3.2 胶片 S 曲线黑位与柔焦光晕（`scripts/film_optics.py` → `film_grade_filter`）

| 试验参数 | 实测直方图与观感 | 结论 |
|---|---|---|
| 旧管线 `gamma=0.95` × 2 | `P05 = 0.0`，`18%–33%` 像素死黑成铁板一块 | ❌ 死黑 |
| `curves='0/0.050 0.14/0.145 ...'` + `halation=0.20`（阈值 `0.66`） | `P05 = 15`，中暗部像蒙了一层牛奶白纱，发灰不通透 | ❌ 起雾（V2 踩坑） |
| `curves='0/0.018 0.10/0.092 ...'` + `sat=0.92` | `P05 = 3.1–3.7` 暗部略紧，肤色饱和度 `0.38` 偏浓 | ⚠️ 略重 |
| **`curves='0/0.034 0.12/0.128 0.50/0.512 0.86/0.855 1/0.968'` + `halation=0.08`（阈值 `0.76`）+ `sat=0.85` + `c0s=3`** | **`P05 = 6.2–7.7`（死黑 `<4.5%`），黑天鹅绒衣褶扎实深邃而不浮灰，高光仅在银发逆光与镀铬麦头处有轻微柔润光晕，颗粒极细不糊细节** | ✅ **定版甜点** |

### 3.3 `episode.json` 可直接复用的混色温灯光与麦克风模板

新剧集只需把以下字段拷进 `episode.json`（按当集年代微调背景名词即可，**保留 `3200K` 暖侧主光 + `5600K` 冷银顶逆发丝光 + `2700K` 暖背景散景的三段结构**）：

```json
{
  "light_en": "authentic mixed-temperature live-action 35mm cinema lighting: warm 3200K tungsten-amber Rembrandt side-key light sculpting natural, healthy warm blood-toned human skin on the lit cheek while the off-key side falls into deep rich solid 4:1 chiaroscuro shadow (zero grey haze, zero cyan skin cast), paired with a crisp 5600K cool-silver overhead back-spotlight beam tracing silver rim highlights along hair and shoulders, and warm 2700K candle chandelier bokeh orbs glowing behind the softly blurred cheering crowd",
  "mic_en": "vintage chrome handheld microphone with a round mesh head",
  "film_look": true
}
```

> **注意**：如果分镜脚本里某条镜头用了 `"raw": true`（自定义完整六段提示词，不走 `_adapt_prompt` 自动拼装），也必须在它的灯光描述里写明 `warm 3200K tungsten-amber Rembrandt key light` + `5600K silver hair rim` + `Cooke Panchro T2.2 shallow depth of field`，切勿遗留 `"cool 5600K concert spotlight"`，否则该镜头会出现单条冷脸跳色。

## 4. 为什么默认不加 Stage-2 `Tessera 2.7K`（算力账单与保留开关）

我们在 G4（RTX PRO 6000 Blackwell 96GB）上实测跑通了 `Stage-1 (1344×768) + Stage-2 ComfyUI-Tessera (2688×1536)` 全链路，并同屏对比了「V3 标准版（无 2.7K）」与「V3 + 2.7K 版」：

| 方案 | 分辨率流向 | 单镜头耗时 / 算力 | 整集（~32–38 镜）预估 | 1080p 成片肉眼观感 |
|---|---|---|---|---|
| **Realism V3 标准版（默认）** | `1344×768` → Lanczos `1920×1080` 单通胶片调色 | ~36 秒 / **`~0.51 CCU`** | **`~12–16 CCU`** | 暖血色肌肤、发丝银边、`r=16` 人群散景、紧致黑位 100% 齐备 |
| Realism V3 + `--tessera-2k`（仅特殊场景备选） | `1344×768` → Tessera 3 步精修 `2688×1536` → 超采缩回 `1920×1080` | ~3.0 分钟 / **`~2.46 CCU`** | `~65–80 CCU` | 300% 局部放大时眉尾/毛孔略锐一丝；正常 1080p 播放几乎无区别 |

**结论**：日常每周 2 集生产**一律不加 `--tessera-2k`**。

若未来制作 4K 频道宣传片需要临时开启 `--tessera-2k`，`scripts/h3_colab_runner.py` 中已固化好 3 项防崩保障，无需重新排障：
1. **Stage-1 断点复用**：Stage-1 跑完立即备份 `<id>_s1_768p.mp4` 到 Google Drive，即使 Stage-2 中断也绝不重烧 Stage-1 算力；
2. **`ComfyUI-Tessera` 上游兼容与 CPU 张量补丁**：自动修补 `core/tiler.py` 中 `_px_shift` 在 GPU tensor 上调 `int()` 的报错，并通过 `/object_info` 动态对齐 `TesseraArgs` 枚举（如上游将 `"blend"` 改为 `"pixel"`）；
3. **96GB 显存阶段切换**：Stage-1 全部跑完后自动关停 `--highvram` 实例，以默认权重卸载模式重启 ComfyUI，避免 `Qwen3-VL-32B` 常驻挤爆 2.7K 分块显存。

## 5. 新剧集一键接入清单（4 步标准命令）

第 4 集起做任何新剧集，按以下 4 步即可零额外成本复刻 V3 电影实拍质感：

```bash
# 1. 在 episodes/<ep>/episode.json 中写入 "film_look": true、混色温 light_en 与 mic_en（见第 3.3 节）

# 2. 生完参考图并裁好 work/stage_a.png、stage_b.png 后，本地一键做 V3 光学景深与暖肤色规整（0 CCU，自动备份 *_raw_orig.png）
python3 workflows/05_ancient_rap_battle/scripts/film_optics.py \
  workflows/05_ancient_rap_battle/episodes/<ep>

# 3. 云端 G4 渲染（Singularity v1.3 12 步，不加 --tessera-2k，单集 ~12–16 CCU）
python3 workflows/05_ancient_rap_battle/run_rap_battle_remote.py \
  workflows/05_ancient_rap_battle/episodes/<ep> \
  --steps 12 \
  --runner-args "--fit --lock-strength 1.0 --mic handheld --realism-v2" \
  --no-post

# 4. 本地无损胶片母带拼接 + 单通 1080p Kodak Vision3 500T 封装（0 CCU）
python3 workflows/05_ancient_rap_battle/scripts/assemble.py \
  workflows/05_ancient_rap_battle/episodes/<ep> \
  --film --out preview/草稿_胶片母带.mp4
python3 workflows/05_ancient_rap_battle/scripts/package.py \
  workflows/05_ancient_rap_battle/episodes/<ep> \
  --src preview/草稿_胶片母带.mp4 --film --1080p --phone
```
