## 1. 核心结论

1. **歌词必须走「人工搭史实/名梗双韵骨架 → Suno Lyrics API 刷律动与地道俚语 → 人工回填守住押韵与典故」三步法**。纯大模型直写的词往往单句音节过密（15+ 音节）导致抢拍；纯 Suno 生成会丢史实和 8+8+8+8 结构；两者结合仅耗 **`0.40` Kie 额度**即可实现 **32 句词对齐命中率 `1.00`**。
2. **有原版配音的经典游戏/影视角色，一律用 Colab L4（`1.71 CCU/h`）跑 `Trained RVC v2` 主力模型，严禁开 G4（`10.05 CCU/h`）做音频**。单集全套分离 + 双引擎 7 组音域转换仅耗 **`~0.55 CCU`**（不到视频渲染的 1/25）。
3. **专属训练 `RVC v2`（`.pth + .index`）在说唱咬字清晰度与节奏锁死度上全面优于零样本 `Seed-VC`**：实测 `RVC v2` 音节包络相关度 `env_r = 0.60–0.70`（对齐误差 `0.0 ~ +2.5 ms`），`2.5–8.5 kHz` 齿音清晰度高出 `+4.5 ~ +6.0 dB`；`Seed-VC` 同机顺带跑出，作为无公开 RVC 模型冷门角色的零样本兜底。
4. **参考干音（`ref_clean.wav`）严禁盲抓混剪视频，必须过「底噪门限 + 低通稳频单说话人逐句门控 + 云端 Demucs 二次提纯」三道关**，否则混入 1 秒女性 NPC 对白或背景 BGM 就会污染 `Seed-VC` 音色与自动基频锚点。

## 2. 全链路五步标准法与量化指标

### 2.1 第一步：双阶段歌词打磨（`0.40` Kie 额度，`0 CCU`）

1. **初稿骨架约束**：严格按 `Round 1 (A 8句 → B 8句) + Round 2 (A 8句 → B 8句)` 共 32 句编写，采用 `AABB` 双韵，单句控制在 **9～13 个英文音节**，每两句绑定一个硬核实锤痛点（销量/奖项对比、剧情名场面、机制/BUG 迷因、幕后工作室争议）。
2. **调用 Suno 官方润色接口**：提交 `POST https://api.kie.ai/api/v1/jobs/createTask`（`model: "ai-music-api/generate-lyrics"`），提取返回双版本中的高冲击力内韵与角色口癖俚语（如 `chest / West / test` 三连内韵、`spooks at a picket fence`、`Dutch's lap dog for two decades`、`that's karma, partner, karma`），回填至 32 句框架中。
3. **段落标签防粘连铁律**：
   - 每段开头写清角色声线提示：`[Verse 1: Arthur Morgan - gritty gravelly Southern outlaw baritone]`；
   - 回合之间必须插入 `[Crowd Interlude]`（如 `OOOH! / TALK TO HIM!`），强制 Suno 留出 **2～18 秒真器乐/欢呼气口**，供分镜切观众欢呼与对手反应镜头。
   - **禁词避坑**：避开疑似制作人署名的短语（如 `"fifty grand"` 会触发 Suno `400` 拒收，改为 `"fifty thousand"`）。

### 2.2 第二步：Suno V6 跨流派配器融合与选曲定长（`13.0` Kie 额度，`0 CCU`）

1. **`suno_style` 配器融合公式**：
   `[角色 A 标志性原声乐器] × [角色 B 标志性原声乐器] + [90–96 BPM] hard-hitting cinematic boom-bap battle rap beat, punchy snare, deep sub-bass, aggressive clear male battle rap vocals`
   - *例（大镖客 vs 巫师）*：`95 BPM` 西部沧桑滑棒木吉他 & 荒原口琴 × 斯拉夫鲁特琴 & 绞弦琴 + 硬核 Boom-Bap 鼓组。
   - **BPM 甜点**：锁定 **`90–96 BPM`**（每小节 `2.5–2.7s`），既保证英文快嘴吐字粒粒分明，又完美契合 MiniMax-H3 单镜 `73–124` 帧生成窗口。
2. **`v1 / v2` 选曲不能只看总分 `match_score`**：
   - 即使两版 `match_score` 均为 `1.00`，也必须检查 `lines.json` 中**每一句的 `end - start` 时长**（尤其是 `A16` 与 `B16`）。若某版跳过了尾奏标签导致 `B16` 被拉长至 `10–30s`（如 `arthur-vs-geralt` 的 `suno_v2`），果断切用每句均稳定在 `2.3–3.0s` 的另一版（通过 `episode.json` 的 `"suno_track": 1` 固定，重跑加 `--reuse` 零费用）。
3. **进拍点与尾奏裁剪（`intro_keep` / `outro_keep`）**：
   - 扫描 `A01` 前的 `0.5s` 窗口 RMS 能量跳变点：将 `intro_keep` 卡在鼓组重拍进场的第 1 拍（通常约 `10.0s`，恰为 95 BPM 的 4 小节前奏）；若保留超长器乐前奏（`"intro_keep": "full"`），务必设 `"title_card_secs": 4.9` 提前淡出大字标题。
   - `outro_keep` 取最后一句唱完后人群呼喊（如 `"LEGEND!"`）自然衰减完的位置（约 `8–10.5s`）。
   - **原档双备份**：裁剪后立即保留 `work/music_trimmed_raw.wav` 与 `work/svc_backups/music_suno_orig.wav`，后续可无限次重跑声线而不破坏时间轴。

### 2.3 第三步：本地 `0 CCU` 声学模型预检与纯净单人参考干音制备

启动云端 GPU 前，必须在本地完成两项零成本校验：

1. **HuggingFace RVC v2 权重存活与内部结构预检**：
   - 用 HTTP `HEAD` / `Range` 请求读取 `.zip` 中央目录，确认返回 `HTTP 200`（剔除 `401` 受限库）、包内同时含 `.pth` 与 `.index`（避免缺索引导致音色发虚），并核对模型卡片语言（剔除土耳其语/波兰语等非英语配音版，保证英文咬字自然）。
   - 每个角色在 `EPISODE_SVC_PRESETS` 中配置 **主备 2 个公开 URL**，防止云端拉取单点失效。
2. **24 秒参考干音（`ref_clean.wav`）三道纯净门控**：
   - **第一关（禁配乐底噪门限）**：计算 100ms 帧 RMS 的第 15 百分位数 `P15`，必须满足 **`P15 < -37 dBFS`**（纯净游戏解包台词停顿处底噪可达 `-45 ~ -58 dBFS`；凡 `> -32 dBFS` 必含背景音乐或混剪 BGM，直接淘汰）。
   - **第二关（低通稳频 + 单说话人逐句门控）**：计算自相关基频前，**必须先过 `< 270 Hz` 低通与 `> 55 Hz` 高通滤波**（消除沙哑男声 2 倍频/3 倍频泛音导致的八度跳变误判），再按静音切分为独立语句（`0.65–18.0s`），仅保留 `F0` 中位数与 `P90` 严格落在目标配音演员生理音域内的语句：
     - *Roger Clark（Arthur Morgan）实机干音*：`F0 P10/P50/P90 = 95.8 / 122.2 / 162.7 Hz`（温暖颗粒感西部男中音）；
     - *Doug Cockle（Geralt of Rivia）实机干音*：`F0 P10/P50/P90 = 74.2 / 86.5 / 132.0 Hz`（`IQR` 仅 `15.0 Hz`，极低沉单调猎魔人胸腔共鸣）。
   - **第三关（云端 Demucs 顺带二次提纯）**：在 L4 上将 `ref_a.wav`、`ref_b.wav` 与主歌一并传入 `demucs.separate -n htdemucs_ft --two-stems=vocals`（仅多耗 1.2 秒），彻底剥离残余环境风声与混响。

### 2.4 第四步：Colab L4 双擎多音域单次批处理（`~0.55 CCU`）

运行 `scripts/run_game_voice_remote.py` 在单次 L4 会话中一次性产出全套干声：

| 引擎 / 档位标签 | 核心机制与参数 | 实测音节锁死度 `env_r` | 高频齿音清晰度 `pres_db` | 定位与适用场景 |
|---|---|---|---|---|
| **`RVC v2` 多档位扫描**<br>(`rvc` / `rvc_fifth` / `rvc_deep` / `rvc_oct` / `rvc_raw0`) | `rmvpe+` 基频提取，`index_influence=0.68`，`consonant_breath_protection=0.33`，`envelope_ratio=0.25` | **`0.602 – 0.699`**（最优） | **`-12.1 ~ -14.0 dB`**（咬字极清脆） | **主力首选母带**：完整保留 Suno 快嘴爆发力与英文辅音颗粒，同时精准注入角色声道共振峰 |
| **`Seed-VC` (`seedvc_f0` / `seedvc_vc`)** | 44.1kHz 扩散声码器，`diffusion_steps=35`，`cfg=0.72`，`auto_f0_adjust=True` | `0.490 – 0.615` | `-15.3 ~ -19.8 dB`（偏柔和） | **零样本兜底备份**：当角色无现成 RVC 模型时，仅凭 24 秒游戏实机干音即可克隆音色 |

> **关键发现：`if_f0=1` 与 `if_f0=0` 两类 RVC 模型的移调规律差异**
> - **带音高条件模型（`if_f0=1`，如 Arthur 的 `morgan_700e_69300s.pth`）**：严格响应 `pitch_lvl` 半音偏置（`0 → -1 → -2 → -3 → -4 st` 实测输出中位数 `133.6 → 126.0 → 120.5 → 112.5 → 106.7 Hz`）。选 `-2 st`（`120.5 Hz`）即可与 Roger Clark 原声（`122.2 Hz`）误差收敛在 `2 Hz` 以内！
> - **纯语调无音高条件模型（`if_f0=0`，如 Geralt 的 `Geralt_e300_s6000.pth`）**：忽略原唱偏高的 `167 Hz` 音高，**原生直接锁定在配音演员训练集的真实声带基频（实测 `90.2 / 91.5 Hz`，贴合 Doug Cockle 原声 `86.5 Hz`）**，既不会因大幅降调产生次声波浑浊伪影，又一秒还原标志性低吼。
> - **正交扫描策略**：在 L4 内存中连续跑 5 组不同 `(pitch_a, pitch_b)` 仅多花约 25 秒（`~0.01 CCU`），将每段干声独立存盘后立即关停 L4；回到本地可用 `--remaster-only --pair-a <tagA> --pair-b <tagB> --out-tag rvc_best` **零算力自由混搭 A、B 各自最佳档位**。

### 2.5 第五步：本地毫秒级对齐、定制 EQ 与流媒体母带定稿（`0 CCU`）

1. **包络互相关毫秒对齐（`align_and_polish_slice`）**：
   - RVC 窗函数与短延迟处理会引入 `±2.5 ~ 15 ms` 微偏移；脚本自动以 `2.5 ms` 步长在 `±50 ms` 窗口内与原版 `demucs_vocals.wav` 做绝对值包络互相关搜索并补偿相位，实测对齐残差 **`0.0 ~ +2.5 ms`**（远小于 24fps 视频单帧 `41.7 ms`），保证下游 MiniMax-H3 口型与 `edl.json` 切点零漂移。
   - 每段首尾施加 `80 ms` 线性余弦交叉淡化，**仅替换 4 段主歌区间的人声**，100% 保留 `demucs_vocals.wav` 中间奏与尾奏的原始人群呐喊声（`"OOOH!"` / `"LEGEND!"`）。
2. **双角色差异化声学塑形与响度目标**：
   - `highpass=85–105Hz` 切净低频浑浊 → `160–220Hz`（`+2.0~2.4dB`）增厚胸腔磁性 → `3000–3400Hz`（`+2.5~3.2dB`）提亮英文齿音穿透力 → `3.2:1` 压缩器稳住字头 → `26–28ms` 极微房间短反射（`0.10`）融进伴奏空间 → 按原人声 RMS 的 `1.12x` 压入 `demucs_no_vocals.wav` 伴奏。
   - **定稿母带硬指标**：积分响度 **`-14.5 LUFS`**（贴合 YouTube `-14 LUFS` 响度标准，不被平台二次压低）、动态范围 **`LRA 2.5–3.2 LU`**、真峰值 **`-0.2 dBFS`（`0.98` 限幅，零削波）**。

## 3. 踩坑复盘与防呆铁律

| 现象 / 踩坑记录 | 根本原因 | 现行标准防护 |
|---|---|---|
| 自动抓取的参考干音转换后音色发尖、偏女声或带和弦底噪 | YouTube 标题含 `"quotes"` 的视频混有 TikTok 配乐混剪（`edit`）或双人对白（如 `Ciri & Geralt` 把中位基频拉高到 `169 Hz`） | 检索词排除 `edit / music / song / compilation`，强制执行 `P15 < -37 dBFS` 底噪门限 + 单说话人 `F0` 区间逐句门控 + 云端 Demucs 二次提纯 |
| 本地自相关测男中音基频误报 `200+ Hz` | 未做低通滤波时，沙哑嗓音的 2 倍频/3 倍频共振峰幅值高于基频周期峰值 | 测 `F0` 前统一先过 `< 270 Hz` 平滑低通与 `> 55 Hz` 去直流滤波，100% 锁定声带真实基频 |
| `yt-dlp` 指定 `-f "ba[abr<=160]"` 或自定义 `player_client` 报 `HTTP 403` | 旧版客户端对低码率 `m4a (itag 140)` 限流，且不识别新版客户端名 | 统一用默认 `-f "bestaudio/best"`（自动走无 403 的 `webm/opus 251` 流）整段快拉到本地再用 `ffmpeg` 切片 |
| 把转换后的 `122s` 母带覆盖成 `song.mp3` 导致后续重裁剪错位 | `analyze_song.py` / `kie_suno.py --reuse` 默认视 `song.mp3` 为**未裁剪的原始全长曲** | **文件契约铁律**：`song.mp3` 永远保持 Suno 原始全长曲；原声转换母带只写 `音乐_最终.wav`、`work/music_final.wav`（成片总混音）与 `work/vocals_final.wav`（驱动 H3 口型纯人声） |
| 单个 HuggingFace RVC 仓库突然设私密返回 `401` | 社区模型作者更改权限 | 开 GPU 前本地先做 HTTP `200` + `.pth/.index` 预检，且每个角色至少配 2 个已验证公开镜像 URL |
