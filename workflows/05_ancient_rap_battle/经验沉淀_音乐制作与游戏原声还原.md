## 1. 核心结论

1. **区分「底层模型真物理边界」与「求稳 SOP 惯性推测」——Suno V6 原生支持单曲剧烈 Beat Switch 与戏剧急停咆哮，且与下游口型管线 100% 兼容**。
   - 此前误以为必须全程锁死单一曲风与匀速唱腔；第 7 集拆解 `kie_suno.py` 源码并实测验证：切干声与算分镜帧数 100% 依赖 Suno 返回的逐词毫秒时间戳 `alignedWords`（而非固定 BPM 网格），只要单句总长落在 H3 窗口（`< 9.4s`）内，无论是 **G-Funk 突变为失真 808 Trap Metal**、句首反问急停怒吼（`"Witness protection"?! For WHAT?!`），还是尾句从 `236 Hz` 咆哮骤降至 `135 Hz` 冷血低语，词对齐命中率均达 **`1.00`**，下游 22 条 H3 口型镜头一次过检（`corr = 0.931–0.999`）。
2. **歌词与曲风标签必须走「人工搭史实/名梗双韵骨架 → Suno Lyrics API 提取母语狠词、缩写防呆与内生曲风标签 → 人工回填守住结构」三步法**（仅耗 **`0.40` Kie 额度**）。尤其要做 Beat Switch 时，直接复用 Suno Lyrics API 返回的 `tags` 碰撞句式（`colliding with... A's verses ride..., B's verses detonate in...`），比人工盲写音乐术语的变奏触发率高得多。
3. **有原版配音的经典游戏/影视角色，一律用 Colab L4（`1.71 CCU/h`）跑专属训练 `RVC v2` 主力模型，严禁开 G4（`10.05 CCU/h`）做音频**。第 7 集单次 L4 会话跑完四轨分离 + 主备两套独立 RVC 模型 6 组档位 + Seed-VC 双模式（共 8 套干声）仅耗时 `8 分 22 秒`、实耗 **`0.11 CCU`（折算 `0.24 CCU`）**。
4. **狂暴撕裂咆哮嗓（Raspy / Screaming Rap）必须单独调高 RVC 气声/辅音保护率（`protect = 0.40–0.44`）并补 `2.45 kHz` 中高频咬字硬度**。默认 `protect = 0.33` 在 `190–255 Hz` 破音嘶吼段容易把喉音颗粒抹成电音；上调至 `0.44`（配合 `+1 st` 微提亮）后，崔佛段落音节锁死度飙至历史最高 **`env_r = 0.722 / 0.744`**，齿音清晰度达 **`-8.03 / -8.41 dB`**。
5. **参考干音（`ref_clean.wav`）严禁盲抓混剪视频，必须过「底噪门限 `P15 < -37 dBFS` + 低通稳频单说话人逐句门控 + 云端 Demucs 二次提纯」三道关**，彻底杜绝背景 BGM 或 NPC 串音污染基频锚点。

## 2. 全链路五步标准法与量化指标

### 2.1 第一步：双阶段歌词打磨与发音防呆（`0.40` Kie 额度，`0 CCU`）

1. **初稿骨架约束**：严格按 `Round 1 (A 8句 → B 8句) + Round 2 (A 8句 → B 8句)` 共 32 句编写，采用 `AABB` 双韵，单句控制在 **9～13 个英文音节**，每两句绑定一个硬核实锤痛点（剧情名场面、玩家社区顶流迷因、幕后砍单轶事、系列销量交棒）。
2. **调用 Suno 官方润色接口提取三大资产**：提交 `POST https://api.kie.ai/api/v1/jobs/createTask`（`model: "ai-music-api/generate-lyrics"`，存档于 `work/suno_lyrics_polish.json`）。注意 Suno 直出稿常会把双方人物关系张冠李戴，因此**绝不能整篇照搬**，而是精准提取三样东西回填进 32 句骨架：
   - **地道母语狠词与松弛开口韵**：如第 7 集提取的 `wearing dirt like cologne`（`throne / cologne` 开口长元音比 `ice / lice` 更易唱出西海岸松弛感）、`silk-suit parasite`、`every score went sideways`；
   - **专有缩写打点防连读（`FIB` → `F.I.B.`）**：不带点的首字母缩略词（如 `FIB`）极易被歌唱前端当成普通单词 *fib* 单音节糊过去；改为 **`F.I.B.`** 后，Suno 100% 准确逐字母重读 `F - I - B`，卡点极炸（同理适用于需逐字母念出的 `C.I.A.`、`D.L.C.` 等）；
   - **Suno 内生曲风碰撞描述词（`tags`）**：直接拷入 `episode.json["suno_style"]`。
3. **戏剧急停咆哮与情绪收束的标点/标签控制**：
   - **句内反问急停切分**：想让角色唱出歇斯底里的停顿再爆发，在句首用引号+双标点（如 `"Witness protection"?! For WHAT?! Nobody took the stand!`），Suno 会自然做出“反问急停半拍 → 破音重砸 `WHAT?!`”的切分律动。
   - **大写词防过滤注意**：切勿把整句英文写成全大写——下游 `assemble.py` 与 Shorts 脚本会用 `isupper()` 自动过滤 `[Crowd]` 里的全大写呐喊词（如 `OOOH!`）；戏剧重音只需大写 1～2 个核心词（如 `For WHAT?!`）即可兼顾演唱爆发力与词轴保留。
   - **禁词避坑**：避开疑似真名制作人 Tag 的短语（如 `"fifty grand"` 会触发 Suno `400` 拒收，改为 `"fifty thousand"`）。

### 2.2 第二步：Suno V6 配器设计（融合模式 vs 单曲剧烈 Beat Switch 模式）

根据题材冲突属性，现已跑通两套成熟曲风范式（均耗 `13.0` Kie 额度，`0 CCU`）：

#### 范式 A：同骨架跨流派配器融合（适合宿命感均衡对决，如历史双雄 / 大镖客 vs 巫师）
- **`suno_style` 公式**：`[角色 A 标志性原声乐器] × [角色 B 标志性原声乐器] + [90–96 BPM] hard-hitting cinematic boom-bap battle rap beat, punchy snare, deep sub-bass, aggressive clear male battle rap vocals`

#### 范式 B：单曲多幕剧烈 Beat Switch（适合性格极端反差对决，如《GTA V》精英伪君子麦克 vs 疯狗崔佛）
1. **`suno_style` 顶层碰撞公式**：用 `colliding with` 明确声明同一首曲子内两套流派与两套唱腔的对撞，同时锚定基础律动 BPM（如 `92 BPM`）：
   ```text
   Battle rap, 90s G-Funk swagger colliding with trap-metal fury, 92 BPM mid-tempo swing with hard snap boom-bap drums and distorted 808 sub drops; Michael's verses ride slick West Coast G-Funk pocket and 80s heist analog synth, Trevor's verses detonate in jagged trap-metal aggression with gritty desert punk guitar; siren risers, sharp turntable cuts between rounds, two contrasting male rappers, crisp English diction
   ```
2. **`structure` 四幕声学与转场音效编排（关键！）**：不要只写干巴巴的 `[Verse 1]` / `[Crowd]`，必须在每个段落 `tag` 里写明**当前幕专属配器 + 物理转场音效触发词 + 角色情绪弧线**：
   - **Verse 1（冷静控场）**：`[Verse 1: Smooth 90s West Coast G-Funk groove, laid-back condescending mob-boss baritone]`
   - **间奏 1（触发第一次剧烈 Beat Switch）**：`[Beat Switch: vinyl brake screech, alarm siren, sudden heavy distorted 808 Trap Metal and desert punk guitar drop]` + `"OOOH!"`（黑胶急刹 + 警报器上升音是让 Suno 彻底切掉前段 G-Funk 贝斯、炸入失真 808 的高可靠开关！）
   - **Verse 2（狂暴反扑）**：`[Verse 2: Distorted Trap Metal 808 bass and desert punk guitar, unhinged snarling raspy male rapper, explosive cadence]`
   - **间奏 2（场景转场桥接）**：`[Bridge: howling blizzard wind, shovel thud on wood coffin, dark synth choir and war drums]` + `"ROUND TWO! ROUND TWO!"`
   - **Verse 3（撕破伪装冷血暗流）**：`[Verse 3: Dark icy heist synth over hard boom-bap drums, cold ruthless mask-off male baritone]`
   - **间奏 3（终局蓄力）**：`[Final Drop: gun cocking click, maximum distorted hardcore sub-bass and roaring guitar climax]` + `"OOOH!"`
   - **Verse 4（咆哮登顶 → 冰冷收束）**：`[Verse 4: Ferocious hardcore hip-hop climax, raw roaring raspy vocal dropping into ice-cold final bars]`
3. **第 7 集 `suno_v1` 四幕 Beat Switch 实测声学验证数据**：
   - **Verse 1（豪宅 G-Funk）**：松弛克制（`RMS -18.4 dB`，超低频 `Sub -1.8 dB`）；
   - **间奏 1 → Verse 2（荒漠 Trap Metal 爆破）**：自动留出 **`13.8s`** 纯变奏器乐窗口（完美容纳《GTA V》标志性三段卫星拉升俯冲切人镜头！），超低频瞬间暴涨 **`+4.3 dB`**；
   - **Verse 3（北杨克顿雪夜摊牌）**：自动压回冷冽暗流（`RMS -19.1 dB`，`Sub -3.9 dB`），麦克基频沉入 `126.0 Hz`；
   - **终局 Drop → Verse 4（掘坟爆发与冰冷终审）**：超低频直接炸高 **`+6.7 dB`**（`-3.9 dB → +2.8 dB`），且崔佛在前 6 句飙至 `235.8–254.9 Hz` 撕裂高音后，最后两句 `"Keep your mansion, Judas — die a traitor, die alone!"` 精准响应 `dropping into ice-cold final bars` 指令骤降至 **`135.3 Hz`** 冰冷宣判，尾奏干净喊出两声 `"WASTED! WASTED!"`。
4. **选曲与句尾静音截齐铁律**：
   - **`v1 / v2` 选曲不能只看 `match_score`**：第 7 集两版对齐分均为 `1.00`，但 `v2` 在 `B16` 后出现 7 秒伴奏抽空且 `A08` 拖长至 13 秒；选曲必须逐段核查超低频能量连续性与每句 `end - start` 分布。
   - **长间奏前的尾句截齐**：当间奏长达 `10–14s` 时，对齐器偶发将转场前尾句（如 `A08`、`B16`）的 `end` 拖入纯伴奏区；必须用 `words_edit.json` 中该句最后一个实唱词的 `t1` 截齐句尾（如 `A08 = 3.37s`、`B16 = 3.01s`），确保全片 32 句 100% 落在 **`2.22s–3.37s`** 黄金窗口。

### 2.3 第三步：本地 `0 CCU` 声学模型预检与纯净单人参考干音制备

启动云端 GPU 前，必须在本地完成两项零成本校验：

1. **HuggingFace RVC v2 主备多仓库存活与结构预检**：
   - 用 HTTP `HEAD` / `Range` 请求确认返回 `HTTP 200`、压缩包内同时含 `.pth` 与 `.index`（优选无 `"trained"` 前缀的推理索引 `added_IVF*.index`），并核对模型语种为原版英语配音。
   - **主备双槽位配置（`rvc_<role>_urls` + `rvc_<role>_alt_urls`）**：对高人气游戏角色，不仅配防失效镜像，还可把**不同训练轮数/索引规模的两个社区模型**分别放进主槽位与 `alt` 槽位（如第 7 集崔佛主槽 `Tsuinzues/trevorphilips [IVF2216]` vs 备槽 `GTA5Trevor_e501_s3997`），在同一次 L4 会话中一并跑出，回本地耳听+指标双选优。
2. **24 秒参考干音（`ref_clean.wav`）三道纯净门控**：
   - **第一关（禁配乐底噪门限）**：100ms 帧 RMS 的第 15 百分位数必须满足 **`P15 < -37 dBFS`**（凡 `> -32 dBFS` 必含背景配乐或混剪 BGM，直接淘汰）。
   - **第二关（低通稳频 + 单说话人逐句门控）**：测自相关基频前先过 `< 270 Hz` 低通与 `> 55 Hz` 高通滤波，按静音切句后仅保留落在目标角色生理音域内的纯净独白。
   - **第三关（云端 Demucs 顺带二次提纯）**：在 L4 上将 `ref_a.wav`、`ref_b.wav` 与主歌一并传入 `demucs.separate -n htdemucs_ft --two-stems=vocals`（仅多耗 1.2 秒），彻底剥离残余环境风声与混响。

### 2.4 第四步：Colab L4 双擎多音域 + 咆哮气声保护单次批处理（`0.11–0.55 CCU`）

运行 `scripts/run_game_voice_remote.py` 在单次 L4 会话中一次性产出全套干声：

| 引擎 / 档位标签 | 核心机制与适用声线 | 实测音节锁死度 `env_r` | 高频齿音清晰度 `pres_db` | 定位与调参要点 |
|---|---|---|---|---|
| **`RVC v2` 标准稳态档**<br>(`rvc` / `rvc_fifth` / `rvc_deep`) | `rmvpe+` 基频提取，`index=0.68`，`protect=0.33–0.40`，`pitch = -2 ~ 0` | `0.581 – 0.699` | `-10.3 ~ -14.0 dB` | **沉稳男中低音首选**（如 Michael `pitch=-1`、Arthur `pitch=-2`、Geralt `if_f0=0`） |
| **`RVC v2` 狂暴撕裂档 (`rvc_grit`)**<br>（第 7 集新增） | `rmvpe+`，**`protect_b = 0.44`（高气声/破音保护）**，**`pitch_b = +1`** | **`0.722 – 0.744`**（历史最高） | **`-8.03 ~ -8.41 dB`**（穿透力极强） | **歇斯底里咆哮 / 沙哑疯批嗓首选**（如 Trevor）：消除高音破音边缘的声码器塑料电音，100% 保住嘶吼喉音颗粒 |
| **`RVC v2` 备选模型槽 (`rvc_alt*`)**<br>（第 7 集新增） | 同会话加载 `rvc_a_alt_urls` / `rvc_b_alt_urls` 第二套权重做交叉验证 | `0.610 – 0.710` | `-9.5 ~ -13.2 dB` | **同机多模型盲测兜底**：仅多花 ~15 秒，杜绝单一社区模型在特定音区翻车 |
| **`Seed-VC` (`seedvc_f0` / `seedvc_vc`)** | 44.1kHz 扩散声码器，`steps=35`，`cfg=0.72`，`auto_f0_adjust=True` | `0.490 – 0.615` | `-15.3 ~ -19.8 dB` | **零样本兜底备份**：无公开 RVC 模型的冷门角色仅凭 24 秒实机干音克隆 |

> **三大核心移调与防破音规律汇总**：
> 1. **带音高条件模型（`if_f0=1`）**：严格响应 `pitch_lvl` 半音偏置。沉稳老炮男中音一般降 `1–2` 半音（如 Michael `pitch_a=-1`，Verse 1 松弛 `206 Hz` → Verse 3 冷血摊牌自动沉入 `126.0 Hz`；Arthur `pitch_a=-2` 收敛至 `120.5 Hz`）。
> 2. **纯语调无音高条件模型（`if_f0=0`）**：如 Geralt `Geralt_e300_s6000.pth`，忽略原唱高音直接锚定配音演员真实胸腔低频（`90.2 Hz`），跨八度低吼零浑浊伪影。
> 3. **撕裂咆哮嗓防电音公式（`pitch = +1` + `protect = 0.44`）**：疯批咆哮角色切忌盲目降调（降调会让 Trap Metal 快嘴糊在低频鼓组里）；微升 `+1` 半音并把 `consonant_breath_protection` 从 `0.33` 提到 `0.44`，让原唱的破音气口与爆发辅音直通输出，音色既像角色本人又保留顶级说唱歌手的撕裂张力。

### 2.5 第五步：本地毫秒对齐、防伴奏掩蔽定制 EQ 与母带 / Shorts 无缝混音（`0 CCU`）

1. **包络互相关毫秒对齐（`align_and_polish_slice`）**：
   - 以 `2.5 ms` 步长在 `±50 ms` 窗口内与原版 `demucs_vocals.wav` 做绝对值包络互相关补偿（第 7 集四段对齐微调分别为 `+5.0 / +2.5 / +7.5 / +2.5 ms`，远小于 24fps 单帧 `41.7 ms`）。
   - 首尾施加 `80 ms` 交叉淡化，**仅替换 4 段主歌区间的人声**，100% 保留 `demucs_vocals.wav` 中间奏与尾奏的原始音效、警报声与呐喊声（`"OOOH!"` / `"ROUND TWO!"` / `"WASTED!"`）。
2. **针对重型 Beat Switch 伴奏的双角色差异化声学 EQ**：
   - **西海岸 G-Funk 沉稳老炮（如 Michael）**：`highpass=88Hz` → `195Hz (+2.2dB)` 增厚胸腔威严磁性 → `3150Hz (+2.6dB)` 提亮字头；
   - **失真 808 / 朋克电吉他重型咆哮（如 Trevor）**：重型电吉他频段极易掩蔽人声中频，因此在 `highpass=98Hz` + `210Hz (+1.6dB)` 基础上，采用**双高频提亮**：**`2450Hz (+1.6dB)` 补喉音咬字硬度** + **`3550Hz (+2.8dB)` 提亮空气齿音穿透力**，确保每一句毒舌咆哮都能干净刺穿失真重低音墙。
   - **定稿母带硬指标**：积分响度 **`-14.5 LUFS`**、动态范围 **`LRA 2.5–4.3 LU`**（Beat Switch 剧集可达 `4.3 LU`，保留从冷峻低语到狂暴轰鸣的真实戏剧反差）、真峰值 **`-0.2 dBFS`（零削波）**。
3. **衍生场景：V2 双人对轰 Shorts 跨段落音乐无缝拼接术（`build_shorts_v2.py`）**：
   - 当制作 `16–18s` 双人对轰 Shorts 需要把相隔几十秒的两段不同曲风（如麦克 G-Funk `A07–A08` 与崔佛 Trap Metal `B01–B04`）拼在一起时，直接硬切总混音会产生人声抢拍残响与波形咔哒声。
   - **标准解法**：在第一段最后一个实唱词结束后，立即用 **`demucs_no_vocals.wav` 纯伴奏轨匹配 RMS 电平**剥离下一句抢拍人声，再锁定两段鼓点相位与变奏前 `0.65–0.80s` 的 Drop 过门做 **`100ms` 升余弦交叉淡化（Raised-Cosine Crossfade）**；结尾在最后一句实唱词落地后 **`+0.14s`** 鼓点处硬切收尾（实测首尾循环跳变 `<= 0.0014`，全片零静音段），兼顾 **0ms 口型同步、零接缝变奏冲击与 100%+ 无缝重播循环**。

## 3. 踩坑复盘与防呆铁律

| 现象 / 踩坑记录 | 根本原因 | 现行标准防护 |
|---|---|---|
| 误以为 Suno 不能中途变奏或急停咆哮而自我阉割编曲张力 | 把前几集求稳用的“匀速单曲风模板”误当成底层代码硬限制 | 遇到戏剧张力强的双雄对决，大胆启用 **范式 B（单曲多幕 Beat Switch）**，`kie_suno.py` 靠 `alignedWords` 逐词毫秒对齐，天然兼容变奏与急停 |
| 英文机构缩略词（如 `FIB`）被唱成普通单音节词（*fib*） | TTS / 歌唱前端对无点全大写短词默认走自然拼读规则 | 凡需逐字母重读的缩写一律加点写作 **`F.I.B.`**（Suno Lyrics API 亦采用此规范） |
| 狂暴咆哮段落经 RVC 转换后高音边缘发虚或带塑料电音 | 默认 `protect=0.33` + 降调把原唱撕裂气声与辅音瞬态过滤掉了 | 在 `rvc_passes` 中增配 **`rvc_grit`（`pitch=+1`, `protect=0.40–0.44`）**，并在混音 EQ 补 `2450Hz` 咬字频段 |
| 长变奏间奏（`13.8s`）前的尾句（`A08` / `B16`）时长被拉到 10 秒以上 | 对齐器将无词纯器乐间奏尾段并入了上一句的 `end` | 生成 `lines.json` 后核对每句 `end - start`，对超长尾句按 `words_edit.json` 最后一个实唱词 `t1` 截齐（锁在 `2.2–3.4s`） |
| 自动抓取的参考干音转换后音色发尖、偏女声或带和弦底噪 | YouTube 混剪视频含背景配乐或双人对白拉偏基频 | 检索词排除 `edit / music / song / compilation`，强制执行 `P15 < -37 dBFS` 底噪门限 + 单说话人低通 `F0` 门控 + 云端 Demucs 二次提纯 |
| 把转换后的母带覆盖成 `song.mp3` 导致后续重裁剪错位 | `analyze_song.py` / `kie_suno.py --reuse` 默认视 `song.mp3` 为**未裁剪的原始全长曲** | **文件契约铁律**：`song.mp3` 永远保持 Suno 原始全长曲；原声转换母带只写 `音乐_最终.wav`、`work/music_final.wav` 与 `work/vocals_final.wav` |
| 单个 HuggingFace RVC 仓库设私密 `401` 或某音区音色不够贴脸 | 社区模型质量与权限参差不齐 | 开 GPU 前本地做 HTTP `200` + `.pth/.index` 预检，并在 `episode.json["svc"]` 同时配主槽 `rvc_*_urls` 与备槽 `rvc_*_alt_urls` 单次跑完 |
