## 3. 节奏规律

| | 曹操一段 | 刘备一段 |
|---|---|---|
| 镜头数 | 13 | 21 |
| 镜头时长中位数 | 2.4 秒 | 1.8 秒 |
| 最短 / 最长 | 1.0 / 6.7 秒 | 0.75 / 5.5 秒 |
| 对手反应镜头 | 2 个 | 3 个 |
| 观众插入 | 1 个 | 2 个 |
| 面对面对峙占比 | 约 18% | 约 30% |

- **后一段比前一段切得快、贴得近**：曹操一段以长镜头和单人近景为主，刘备一段镜头数多六成，后 17 秒几乎全在两人贴脸的双人镜头里来回切。全片的升级感来自这里。
- **每段都是「远 → 近」的同一套进场**：观众背影远景 + 铭牌 → 推到全身 → 推到中景。
- **对峙双人里，唱的人永远在画面右侧**，听的人在左侧、背侧对镜头。也就是说两段之间两人换了边。
- **反应镜头都很短**（0.75～2.1 秒），都放在句子中间，声音不断。
- **有两处连动**：B5 的甩镜直接落到 B6 的曹操身上；B11 是从过肩中景急推到大特写。
- **过肩拍听者的镜头（A3）里唱的人只有背影**，不需要对口型。

## 4. 画面设定（原片的，供对照，不照搬）

- 场景是室内酒肆：木梁柱、红灯笼、墙上有「酒」字招牌，舞台只有一束冷白顶光加烟雾，四周是暖色灯笼光。
- 两人都手持麦克风，**没有道具**。麦克风经常压在画面底部前景，是广角贴脸镜头的主要视觉元素。
- DJ 是现代打扮（墨镜、黑 T 恤、笔记本电脑、现代唱机），观众里也混着戴墨镜的人，是有意的穿越感。
- 文字：片头片尾片名叠左侧，铭牌在左下，歌词一行金色小字居中靠下。
